# Conventions of this project

For this project, we must use the follow conventions:

### PascalCase

For classes, interfaces and types. For example: `TransitService.ts`.

### camelCase

For variables, methods and functions. For example: `getCityData()`.

### SCREAMING_SNAKE_CASE 

For global constants. For example: `DEFAULT_PORT`.

### kebab-case

For file names. For example: `geo.controller.ts`.
